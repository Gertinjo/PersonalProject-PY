# PersonalProject-PY

🎓 Student Grade Management System

A full-stack Python application for managing students, teachers, classes, and grades. The project combines modern Python technologies including FastAPI, Pydantic, SQLite, Streamlit, Pandas, Plotly, Uvicorn, web scraping, CSV data processing, and environment-based configuration.

📚 Project Overview

The Student Grade Management System is designed to help educational institutions manage:

Student information
Teacher information
Class assignments
Student grades
Teacher-to-student enrollment relationships
Grade analytics and visualization
CSV import/export
External educational data collection through web scraping

The system provides:

REST API built with FastAPI
SQLite database for persistent storage
Streamlit dashboard for administration and analytics
Interactive charts using Plotly
Data validation with Pydantic
CSV grade imports
Environment variable management using .env
Web scraping for external educational information
